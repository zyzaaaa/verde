Что такое сайт

Сайт — это набор связанных веб-страниц, которые открываются в браузере по одному адресу. Каждая страница — это файл с кодом, а браузер читает его и показывает текст, картинки и кнопки.

Основа любого сайта — три языка: HTML создаёт структуру и текст, CSS отвечает за цвета и оформление, JavaScript добавляет действия, например кнопки и анимацию.

Чтобы сайт увидели другие, его размещают на хостинге: это компьютер, который всегда включён и отдаёт ваши файлы всем, кто открыл адрес.

За что отвечает HTML

HTML отвечает за структуру и содержание страницы. Он говорит браузеру, что находится на странице: заголовок, абзац, картинка, кнопка или ссылка.

Каждый элемент записывается тегом, например <h1> для заголовка, <p> для абзаца и <button> для кнопки. Без HTML у сайта не было бы основы, а CSS и JavaScript нечего было бы оформлять и оживлять.

За что отвечает CSS

CSS отвечает за внешний вид страницы: цвета, шрифты, размеры, отступы и расположение элементов. Он говорит браузеру, как показать то, что написано в HTML.

Правило записывается просто: выбираете элемент и задаёте ему свойства, например цвет фона или размер текста. Через CSS делаются и плавные эффекты: подсветка кнопки при наведении и появление текста.

За что отвечает JavaScript

JavaScript отвечает за поведение страницы: он реагирует на действия человека. Нажатие на кнопку, переключение экранов, проверка формы, калькуляторы и игры работают благодаря ему.

JavaScript работает прямо в браузере и меняет страницу на лету. На этом сайте он делает одно: по нажатию «След.» прячет один экран и показывает следующий.
